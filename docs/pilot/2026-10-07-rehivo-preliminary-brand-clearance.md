# REHIVO preliminary brand-clearance note — 2026-10-07

Status: preliminary screen only; not legal clearance and not a substitute for an Indian trade mark attorney/agent search.

## Executive decision

**Preliminary rating: MODERATE RISK — survives public-web screening, but do not publicly rebrand or file until an exact + phonetic + deceptive-similarity Indian registry search is completed.**

Why this is not LOW RISK yet:
- No obvious healthcare, physiotherapy or Indian SaaS business using the exact word REHIVO surfaced in the public web screen.
- A close spelling, **REHIVA**, is in active commercial use by Rehiva Oy in Finland for home-energy services. It is a different industry and geography, but is phonetically/visually close enough to include in professional clearance.
- The exact sequence `rehivo` appears in a developer username (`ricky-rehivo`) associated with software packages. That is not evidence of a healthcare trade mark, but it means the string is not globally unused.
- General web indexing is not an authoritative substitute for the Indian Trade Marks Registry exact/phonetic/deceptive-similarity search.

## Filing priority for the current business model

### Class 42 — first priority
The present core is hosted software/SaaS: a physiotherapy practice workspace plus online discovery/scheduling functionality. For a limited-budget individual applicant, Class 42 is the strongest first filing candidate.

### Class 35 — second / conditional priority
Relevant if REHIVO is deliberately operated as a patient-to-physiotherapist marketplace/directory/lead-matching business. The exact specification should be drafted narrowly with counsel so the filing describes the real service rather than claiming unrelated business services.

### Class 44 — defer unless the platform itself provides clinical care
Class 44 covers medical/healthcare services. The current product position is that independent physiotherapists provide clinical care and remain responsible for it. Filing Class 44 merely because the users are physiotherapists would blur that platform/clinician boundary. Consider Class 44 only if REHIVO itself later becomes the provider of physiotherapy/healthcare services.

### Class 9 — defer for the web-only pilot
Class 9 is relevant to downloadable software/apps. The present pilot is primarily hosted web software. Revisit when there is a downloadable/native app or another real Class 9 use case.

## Official fee baseline checked on 2026-10-07
IP India lists TM-A e-filing at **₹4,500 per mark per class** for an Individual / Startup / Small Enterprise. Therefore one class is ₹4,500 government fee; two classes are ₹9,000 government fee. Professional/agent fees are additional.

## Use basis
The safest current assumption is **proposed to be used** unless there is documentary evidence that REHIVO has already been used publicly/commercially as a trade mark. Do not invent an earlier-use date. IP India states that prior-use claims require an affidavit and supporting evidence; proposed-to-be-used applications do not require prior-use evidence.
